# Handwritten Digit Recognition System

An interactive, educational web application for drawing, predicting, and understanding handwritten digits. This project demonstrates how neural networks learn and make decisions by visualizing their internal states layer by layer.

## Features

- **Interactive Drawing Canvas**: Draw a digit (0-9) directly in the browser. The image is preprocessed (scaled to 28x28, normalized) exactly as it is in standard MNIST datasets.
- **Custom NumPy Neural Network**: A fully-connected neural network (784 -> 128 -> 64 -> 10) implemented purely in NumPy from scratch.
- **PyTorch CNN Integration**: A Convolutional Neural Network (CNN) built in PyTorch serving as a high-accuracy baseline for comparison.
- **Live Comparisons**: Draw a digit and see real-time side-by-side predictions from both the NumPy Neural Network and the PyTorch CNN.
- **Interactive Visualizers**:
  - **Network Visualizer**: Inspect the architecture, weights, and biases of the NumPy Neural Network.
  - **CNN Feature Maps**: Watch how the CNN processes your drawing layer-by-layer through convolutions and max-pooling operations. View interactive heatmaps of the real intermediate tensors.
- **Training Dashboard**: Train the NumPy neural network live in your browser and monitor real-time epoch, batch, loss, and accuracy metrics.

## Tech Stack

### Frontend
- **React 18** with **TypeScript**
- **Vite** for fast bundling
- **Tailwind CSS** for styling
- **Lucide React** for icons
- Custom HTML5 `<canvas>` rendering for fast, real-time heatmaps.

### Backend
- **Python 3**
- **FastAPI** for a fast, async REST API
- **NumPy** for custom neural network training and inference
- **PyTorch** for CNN inference
- **Uvicorn** as the ASGI server
- **Pytest** for backend unit testing

## Getting Started

### Prerequisites
- Python 3.10+
- Node.js 18+

### 1. Setup the Backend
Navigate to the `backend` directory and install the requirements (a virtual environment is recommended).
```bash
cd backend
python -m venv venv

# On Windows
venv\Scripts\activate
# On macOS/Linux
source venv/bin/activate

pip install -r requirements.txt
```

### 2. Start the Backend Server
Run the FastAPI backend on `http://localhost:8000`:
```bash
uvicorn app.main:app --reload
```
*Note: The backend requires the pre-trained weights in `backend/weights/model.npz` and `backend/weights/cnn_model.pt` which are generated by the training scripts.*

### 3. Setup and Start the Frontend
In a new terminal, navigate to the `frontend` directory:
```bash
cd frontend
npm install
npm run dev
```
The frontend will start on `http://localhost:5173`. Open this URL in your browser to interact with the application.

## Project Structure

- `frontend/`: React + Vite application. Contains pages for Recognition, Network Inspection, Model Comparison, CNN Visualization, and Training.
- `backend/`: FastAPI application.
  - `app/api/`: API routers for dataset processing, custom model inference, and CNN inference.
  - `app/model/`: Neural network implementations (NumPy and PyTorch).
  - `scripts/`: Offline training scripts for the models.
  - `tests/`: Pytest suite covering all API endpoints and model logic.

## Educational Goal
This project is designed to be beginner-friendly. It avoids "black boxes" by exposing intermediate activations, allowing users to physically see what a network learns when it detects a digit.
