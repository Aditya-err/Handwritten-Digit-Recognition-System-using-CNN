# Handwritten Digit Recognition System using CNN

This repository contains a comprehensive academic project focused on Handwritten Digit Recognition. It features a high-accuracy Convolutional Neural Network (CNN) built with TensorFlow/Keras, alongside a modern interactive web application that allows you to draw digits and visualize how neural networks process them in real-time.

---

## 🧠 Part 1: The Core Deep Learning Model (Jupyter Notebook)

The original foundation of this project is a robust CNN built and trained on the MNIST dataset using **TensorFlow and Keras**. This can be found in the `OLD/` directory.

### Key Highlights
- **Dataset**: MNIST (70,000 grayscale images of 28x28 pixels).
- **Architecture**: A 3-block Convolutional Neural Network:
  - `Conv2D` layers (32, 64, 128 filters) for feature extraction.
  - `BatchNormalization` for faster, more stable training.
  - `MaxPooling2D` for spatial downsampling.
  - `Dropout (0.5)` to prevent overfitting.
  - `Dense` layers leading to a 10-class softmax output.
- **Optimization**: `Adam` optimizer with `ReduceLROnPlateau` (dynamic learning rate) and `EarlyStopping`.
- **Accuracy**: Achieves **99%+ accuracy** on the unseen test set.
- **Evaluation**: Includes detailed visualizations of training curves, a Seaborn Confusion Matrix, and a Scikit-learn Classification Report.

You can explore the training process, data exploration, and evaluations in the [Handwritten_Digit_Recognition_CNN.ipynb](OLD/Handwritten_Digit_Recognition_CNN.ipynb) notebook.

## 💻 Part 2: Interactive Web Application

To make the models educational and interactive, we built a full-stack web application. It allows users to physically draw digits on a canvas and visualize exactly what the neural networks "see" layer by layer.

### Web App Features
- **Drawing Canvas**: Draw a digit (0-9) directly in the browser. The image is preprocessed (scaled to 28x28, normalized) exactly like the MNIST dataset.
- **Live Comparisons**: Draw a digit and see real-time side-by-side predictions from different models.
- **Interactive Visualizers**:
  - **CNN Feature Maps**: Watch how a PyTorch CNN processes your drawing layer-by-layer through convolutions and max-pooling operations. View interactive heatmaps of the real intermediate tensors.
  - **Network Visualizer**: Inspect the architecture, weights, and biases of a custom-built NumPy neural network.
- **Training Dashboard**: Train a custom NumPy neural network live in your browser and monitor real-time epoch, batch, loss, and accuracy metrics.

### Tech Stack
- **Deep Learning**: TensorFlow/Keras (Original Colab Notebook), PyTorch (Web CNN Inference), NumPy (Custom NN from scratch)
- **Backend**: FastAPI, Python 3
- **Frontend**: React 18, TypeScript, Vite, Tailwind CSS, Lucide Icons

## 🚀 Getting Started with the Web App

### Prerequisites
- Python 3.10+
- Node.js 18+

### 1. Setup the Backend
Navigate to the `backend` directory and install the requirements (a virtual environment is recommended).
```bash
cd backend
python -m venv venv

# On Windows
venv\Scripts\activate
# On macOS/Linux
source venv/bin/activate

pip install -r requirements.txt
```

### 2. Start the Backend Server
Run the FastAPI backend on `http://localhost:8000`:
```bash
uvicorn app.main:app --reload
```
*Note: The backend requires the pre-trained weights in `backend/weights/model.npz` and `backend/weights/cnn_model.pt` which are generated by the training scripts inside `backend/scripts/`.*

### 3. Setup and Start the Frontend
In a new terminal, navigate to the `frontend` directory:
```bash
cd frontend
npm install
npm run dev
```
The frontend will start on `http://localhost:5173`. Open this URL in your browser to interact with the application.
